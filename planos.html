Para clientes, o match.IA é e sempre será gratuito

Quem procura um arquiteto nunca paga nada, nunca vê um limite e nunca esbarra num paywall — em nenhuma etapa. O plano abaixo é só para arquitetos.

Gratuito

R$0

Para começar a aparecer no match e conduzir seu primeiro projeto pela plataforma.

  • Perfil completo e assinatura do seu jeito de projetar
  • Apareça nos resultados de compatibilidade, por mérito
  • Até 3 peças no portfólio
  • Espaço do projeto em 1 projeto ativo por vez: etapas com aprovação, arquivos (20 MB) e lista de compras
  • Biblioteca de até 20 itens por projeto
  • Assistente de IA: 10 mensagens por dia
  • Últimas 5 mensagens de cada conversa
  • Estúdio 3D
  • Selo Pro e prioridade nos resultados
Recomendado

Pro

R$79/mês

Para quem toca vários projetos ao mesmo tempo e quer a plataforma inteira trabalhando com a sua assinatura.

  • Tudo do plano Gratuito
  • Espaço do projeto em todos os seus projetos, com 80 MB de arquivos em cada
  • Biblioteca ilimitada, reaproveitada de um projeto para o outro
  • Assistente de IA sem limite diário e conceito do projeto escrito pela IA com a sua assinatura
  • Estúdio 3D: objetos e planta baixa em 3D para compartilhar com o cliente (quando liberado)
  • Portfólio ilimitado e histórico completo de mensagens
  • Métricas do perfil e selo "Pro" visível
  • Prioridade nos resultados — um bônus, não um topo garantido: mérito real (nota, histórico de projetos fechados) sempre conta mais

O Pro nunca muda a % de compatibilidade que o cliente vê — isso continua calculado só pelo quanto seu portfólio combina com o projeto dele.

Modelo de negócio

Como o match.IA se sustenta

Nenhuma cobrança abaixo é real — este é um projeto acadêmico (TCC), sem gateway de pagamento.

1. Assinatura Pro do arquiteto

Um valor mensal baixo e opcional (R$79), abaixo das ferramentas de gestão de escritório e de obra do mercado, para quem conduz vários projetos pela plataforma. O Gratuito continua completo para um projeto por vez, e o Pro nunca substitui o mérito nos resultados, só soma a ele.

2. Comissão quando um projeto fecha

Quando cliente e arquiteto confirmam que o projeto saiu do papel pela plataforma, uma pequena comissão simulada é registrada — o arquiteto só "paga" quando o match realmente vira negócio.

3. Comissão com lojas parceiras

Durante o projeto, a IA identifica produtos (materiais, móveis, iluminação) que combinam com o que está sendo desenvolvido e sugere opções de lojas parceiras — a plataforma recebe uma comissão sobre a indicação. Cliente e arquiteto nunca pagam nada por isso.

Perguntas frequentes

Antes de assinar

Um arquiteto Pro sempre aparece na frente?

Não. O Pro dá um bônus de pontos na ordenação, mas a nota, o histórico de projetos fechados pela plataforma e as avaliações contam mais — um perfil free com mérito melhor continua na frente de um Pro fraco.

Se eu estiver no Gratuito, meu cliente perde alguma coisa?

Não. O cliente nunca paga e nunca esbarra em limite: ele vê o Espaço do projeto, aprova etapas e arquivos e usa a lista de compras do mesmo jeito. Os limites do Gratuito valem só para o que você, arquiteto, faz — como editar o espaço de mais de um projeto ativo ao mesmo tempo.

Posso cancelar quando quiser?

Sim. Como é uma assinatura mensal, você pode voltar para o plano gratuito a qualquer momento pelo seu painel.

O plano gratuito é limitado para sempre?

Sim, o plano gratuito não expira — ele só tem os limites descritos acima.

Isso é uma cobrança real?

Não. O match.IA é um projeto acadêmico (TCC) — este checkout é uma simulação para demonstrar o modelo de negócio, sem gateway de pagamento nem cobrança de verdade.
